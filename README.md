# Вешање

Игра вешања (hangman) на српској ћирилици. Отвори `index.html` у прегледачу.

- 30 слова азбуке, распоред по азбуци или као на тастатури
- теме: животиње, храна, градови у Србији, природа, кућа и школа
- 8 грешака; „Откриј слово“ открива једно слово и кошта један покушај
- куцање ћирилицом или латиницом (Q = Љ, W = Њ, X = Џ)
